\begin{block}{Introduction}
    The \textbf{HRIA Poster Theme} is a modern theme based on \texttt{beamerposter} that
    uses semi-official \emph{HRIA branding}\footnote{\url{https://hria.upb.ro}}. Some
    of its elements and styling are inspired by \emph{Gemini}
    theme\footnote{\url{https://github.com/anishathalye/gemini/}}.

    \medskip
    It comes with a few nifty features:
    \begin{itemize}
        \item Use of a consistent color scheme throughout.
        \item Customized block environments.
        \item Easy to extend and modify separate parts (header, fonts, etc).
    \end{itemize}

    \medskip
    Separate parts are available as e.g. \texttt{\textbackslash usecolortheme\{hriaposter\}}!
\end{block}

\begin{block}{Colors and Fonts}
    This theme uses the \emph{Adobe Source Sans Pro} font. This is a clean \emph{sans serif}
    font from Adobe that will make your poster look cool.

    \medskip
    The theme has three standard colors:
    \begin{itemize}
        \item A nice \textcolor{HRIALightBlue}{\textbf{light blue}} (\texttt{HRIALightBlue}).
        \item A bolder \textcolor{HRIADarkBlue}{\textbf{dark blue}} (\texttt{HRIADarkBlue}).
        \item An attention grabbing \textcolor{HRIAGreen}{\textbf{green}}
        (\texttt{HRIAGreen})!
        \item Variants \texttt{color!x} can also be used to darken or lighten them
    \end{itemize}

    \medskip
    These can be used for emphasizing text with obvious \alert{alerts}. Standard
    \textbf{bold} can, of course, also be used!
\end{block}
